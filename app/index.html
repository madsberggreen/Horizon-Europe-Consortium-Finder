research-funding plugin for Claude

Horizon Europe Consortium Finder

Start in Claude

The form now opens inside Claude. Type this in a new chat:

/start

Fill in the form, choose simple or advanced search and press Find me a consortium!. Claude then generates the reports.

Not installed yet?

  1. In Claude, open Customize → Plugins.
  2. Click Add → Add marketplace → Add from a repository and enter madsberggreen/Horizon-Europe-Consortium-Finder.
  3. Open Discover, search for research-funding and click Install.

Full guide: github.com/madsberggreen/Horizon-Europe-Consortium-Finder
